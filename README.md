# sites on cookiejar.lol

The installable agent skill and Claude Code plugin for Cookiejar hosting, records, files,
domains and secrets. One key per person, one site per project.

Start at the complete canonical manual: https://cookiejar.lol/agent/.
The SKILL.md below is generated from the same source, including onboarding and API examples.

Claude Code:

    claude plugin marketplace add rkz211/cookiejar
    claude plugin install sites@cookiejar

Other agents: fetch https://raw.githubusercontent.com/rkz211/cookiejar/main/skills/sites/SKILL.md
and follow it. This repository is the public distribution; edit the canonical manual in the
service repository and regenerate, rather than editing this published copy.
